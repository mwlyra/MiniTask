# MiniTask 1.1.4 — Public beta

- Download and run a single **MiniTask.exe**, with no ZIP to extract.
- A smaller download with fewer bundled components.
- A lighter system tray implementation, with the same restore, stop, and exit controls.
- Start a new recording with **F8** or **Rec** without a save prompt. Click **Save** first to keep the previous one.
- Enable optional start and stop sounds under **Prefs → Sound cues**.
- MiniTask is open source under the MIT license.

Download **MiniTask.exe** below and open it. Requires Windows 11, 64-bit; no installer or separate .NET download is needed.

Close MiniTask before replacing the old executable. Your recordings and preferences carry over.

This is a public beta. If something does not work as expected, [report an issue](https://github.com/mwlyra/MiniTask/issues) with your Windows version and the steps to reproduce it.
